Create flashcards with any AI model

You can use ChatGPT, Claude, Gemini, or any other LLM to create cards, then paste them directly into a Zuppi deck.

1. Copy this prompt into your AI model

Create 20 useful flashcards about [YOUR TOPIC].
Return ONLY tab-separated values with no heading and no markdown.
Each line must contain exactly two columns:
front<TAB>back
Do not use tabs inside either column. Keep each front focused on one question and each back concise.

Example:
What is photosynthesis?<TAB>The process plants use to convert light energy into chemical energy.

Topic: [YOUR TOPIC]

2. Copy the generated rows

Ask the model to return only the rows. Do not copy code fences, numbering, bullet points, or an explanation. TSV is recommended because tabs are less likely than commas to appear inside normal sentences.

3. Paste them into Zuppi

  1. Open the deck where you want the cards.
  2. Choose Paste CSV.
  3. Paste the generated rows.
  4. Confirm that the preview shows the front and back in separate columns.
  5. Import the cards.

CSV format

If your model creates comma-separated CSV instead, use this format. Fields containing commas must be surrounded by double quotes.

What is spaced repetition?,A study method that schedules reviews over increasing intervals.
What is FSRS?,A modern algorithm for scheduling flashcard reviews.
"What is Zuppi?","A private flashcard app for iPhone, iPad, and Mac."

Tip: Always review AI-generated cards before importing them. AI can produce incorrect or oversimplified information, especially for medical, legal, or scientific topics.
